# Embrace Community Care Website

A professional, responsive website for a community care / aged care organisation.

## About

This project is a full single-page website designed for **Embrace Community Care**.  
It showcases services, locations, news, and a contact form with a modern, accessible design.

Built as a real-world front-end practice project focusing on clean layout, responsive design, and user experience.

## Features

- Sticky navigation with mobile menu
- Hero section with call-to-action
- Services and about cards
- Locations section
- News / updates section
- Contact form
- Scroll animations
- Fully responsive design

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript

## How to Run

The full website code is currently contained in the repository.  
Open the main HTML file in any modern browser to view the site.

```bash
git clone https://github.com/ankitsapkota2002-boop/My-first-website.git
```
